Task 1 Thu Thập Văn Bản Pháp Luật

Tải về ≥3 văn bản pháp luật dạng PDF/DOCX về ma tuý (Luật 73/2021, NĐ-105, BLHS 2015 Chương XX…) vào data/landing/legal/

PDF / DOCX data/landing/legal/
Task 2 Crawl Bài Báo

Crawl ≥5 bài báo về nghệ sĩ Việt Nam liên quan tới ma tuý bằng Crawl4AI. Lưu metadata: URL, ngày crawl, tiêu đề.

Crawl4AI JSON / HTML data/landing/news/
Task 3 Convert Sang Markdown

Dùng MarkItDown (Microsoft) để convert toàn bộ PDF/DOCX/HTML thành Markdown, lưu vào data/standardized/.

MarkItDown data/standardized/
Task 4 Chunking & Indexing

Chọn chunking strategy (RecursiveCharacter / MarkdownHeader / Semantic), embedding model BAAI/bge-m3, index vào Weaviate.

LangChain Splitters Weaviate bge-m3
Task 5 Semantic Search

Dense retrieval trên vector store. Trả về [{content, score, metadata}] sorted descending theo cosine similarity.

Dense Retrieval top_k=10
Task 6 Lexical Search (BM25)

Triển khai BM25 bằng rank-bm25. Bonus +5đ nếu dùng Elasticsearch hoặc Weaviate BM25 built-in.

BM25Okapi rank-bm25
Task 7 Reranking

Cross-encoder reranker (jina-reranker-v2-base-multilingual hoặc Qwen3-Reranker-0.6B) hoặc RRF/MMR tự implement.

Cross-encoder RRF / MMR
Task 8 PageIndex Vectorless RAG

Upload tài liệu lên PageIndex và viết function pageindex_search() làm fallback khi hybrid search cho kết quả thấp.

PageIndex SDK Vectorless
Task 9 Retrieval Pipeline Hoàn Chỉnh

Kết hợp Semantic + BM25 → Merge (RRF) → Rerank → fallback PageIndex nếu score < threshold.

Hybrid Search Fallback Logic
Task 10 Generation Có Citation

Reorder chunks (tránh "lost in the middle"), inject vào SYSTEM_PROMPT, gọi LLM trả lời có citation dạng [Nguồn, Năm].

Lost-in-Middle fix Citation OpenAI / Gemini
